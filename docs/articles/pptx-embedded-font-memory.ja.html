PowerPoint は、閉じたファイルのフォントを覚えている

同じ .pptx を PDF に書き出しているのに、書き出すたびに字の形が変わる。原因を追うと、PowerPoint が「さっき閉じたファイル」の埋め込みフォントを覚えていたことが分かりました。

Oxi は PowerPoint の出力を「正解」にしている

Oxi は、Word・Excel・PowerPoint のファイルをブラウザで表示するオープンソースのエンジンです。表示がどれだけ正確かを、本物のアプリが書き出した PDF と 1 枚ずつ画素で比べて測っています。スライドなら、PowerPoint が書き出した PDF が「正解」です。

ところがある日、正解の PDF を書き出し直したら、何も変えていないファイルで字の太さや形が変わりました。正解の側が揺れていたのです。

PowerPoint が使えるフォントは 3 か所にある

まず前提です。スライドで指定されたフォントを、PowerPoint は次の 3 か所から探します。

  1. パソコンに入っているフォント（Windows の Fonts フォルダー）
  2. Office のクラウドフォント（Microsoft 365 が必要に応じてダウンロードするもの）
  3. ファイルに埋め込まれたフォント（「ファイルにフォントを埋め込む」で保存したもの）

同じ名前のフォントが複数の場所にあると、どれを使うかで見た目が変わります。たとえば Montserrat は、クラウドには Regular（400）があり、あるファイルには Medium（500）が「標準の太さ」として埋め込まれていました。

実験：ファイルを続けて書き出すと、前のファイルの影響が残る

どの条件で選び方が変わるのかを確かめるため、フォントの埋め込み方だけを変えた小さなテスト用のファイルをいくつも作り、PowerPoint の自動操作で PDF に書き出しました。最初は 1 つの PowerPoint の中で、ファイルを次々に開いては閉じていました。

すると、おかしな結果が出ました。Poppins を埋め込んだファイル A を書き出して閉じたあと、同じ PowerPoint で Poppins を使うが埋め込んでいないファイル B を書き出すと、B の Poppins が Calibri に置き換わっていたのです。

つまり PowerPoint は、ファイルを閉じても、そのファイルに埋め込まれていたフォントをアプリが終了するまで覚えています。そして、あとから開いた別のファイルのフォントの選び方が、その記憶に引きずられることがあります。

図1 の「細い字と太い字」の食い違いも、書き出したときの状態に左右されていました。そのときクラウドにどのフォントがあったか、そして PowerPoint がそれまでにどのファイルの記憶を抱えていたか。この 2 つによって、正解の PDF が変わっていたのです。

もう 1 つの落とし穴：埋め込んでいても読まれないことがある

実験の途中で、もう 1 つ分かったことがあります。.pptx の中にフォントのデータが入っていても、ファイル全体に「埋め込みフォントを使う」という印（embedTrueTypeFonts="1"）がなければ、PowerPoint はそのフォントを読みません。

ほかのツールでスライドを作ったり書き換えたりするときは、フォントのデータとこの印の両方がそろっているかを確かめてください。

Oxi はどうしたか

  • PowerPoint の正解 PDF を、1 ファイルごとに PowerPoint を起動し直してすべて書き出し直しました。
  • 書き出したときのクラウドフォントの在庫も一緒に記録し、あとから「どの条件で作った正解か」を追えるようにしました。
  • 前に書き出した正解は消さずに残し、新旧を比べられるようにしています。

正解が揺れていると、Oxi の表示を直しても、それが良くなったのか悪くなったのかが分かりません。測る道具をまず安定させる。地味ですが、いちばん大事な作業でした。

PowerPoint を使う方へのヒント

  • 複数のファイルをまとめて PDF にするときは、念のため 1 ファイルごとに PowerPoint を終了してから次を開くと、前のファイルの影響を受けません。
  • 人に渡すファイルの見た目を確実に揃えたいときは、フォントを埋め込んだうえで、相手の環境でも一度開いて確かめるのが安全です。
  • 同じファイルでも、パソコンや Office のクラウドフォントの状態によって、字の太さが変わることがあります。

この記事の内容は、2026 年 11 月に Windows 版 Microsoft 365 の PowerPoint で確かめたものです。PowerPoint の版や設定によって、振る舞いが変わる可能性があります。
