# Oxi Slides

Open PowerPoint decks (`.pptx`) in [Orca](https://www.onorca.dev)'s editor as slides. Without it, Orca shows a `.pptx` as "Binary file — cannot display".

It is a viewer, made for decks your agents write: ask an agent for slides, open the `.pptx` it saved, and read them in the tab. When the agent rewrites the file, the tab redraws on the slide you were reading. The viewer itself never changes the file.

- **Slides:** the slide list on the left and the selected slide on the right, with text, shapes, pictures, tables and the slide master.
- **Slide show:** the button in the status bar plays the deck full screen. Arrow keys and Space move between slides, and Esc ends.
- **Local:** the slides are laid out by [Oxi](https://github.com/Ryujiyasu/oxi), an open-source document engine written in Rust and compiled to WebAssembly. It runs inside Orca's sandboxed editor frame. The deck is never uploaded, and the plugin makes no network requests.

## Limits

- `.pptx` only. Legacy `.ppt` and password-protected decks are not opened.
- No editing: change a deck through your agent, or in a presentation app.
- Some content may not be drawn yet or may look different from PowerPoint, for example some charts, SmartArt, video and audio. Animations and transitions are not played.
- A typeface the machine does not have is drawn with an installed one, so line breaks can differ from PowerPoint.
- Desktop app only. Browser clients (`orca serve`) cannot run it, because the engine is WebAssembly loaded from the plugin folder.

## Source and licence

This repository holds the built plugin. It is generated by [`integrations/orca`](https://github.com/Ryujiyasu/oxi/tree/main/integrations/orca) in the Oxi repository, from the same page (`web/index.html`) as the Oxi web editor and the VS Code extension. `editor/oxidocs_engine.*.wasm` is the engine (`crates/oxidocs-wasm`, built with `--features slides,external-font-catalog`), split into parts that the page joins, because Orca serves at most 16 MiB of WebAssembly per file. Each part is a small WebAssembly module whose custom section `oxi-engine-part` holds one slice of the engine.

The engine is MPL-2.0. The WebAssembly bindings and the plugin's glue code are MIT OR Apache-2.0.
